Idea del proyecto


Desarrollar una aplicación móvil para una empresa, con el objetivo de facilitar el acceso a información y servicios de la empresa desde un teléfono celular.

La aplicación permitirá centralizar las principales funcionalidades que necesitan los usuarios y mejorar la comunicación y gestión de los servicios de la empresa.


Tecnologías
Android Studio
Java / Kotlin
Git y GitHub

Objetivo

Crear una aplicación móvil funcional que permita a la empresa ofrecer sus servicios de manera más accesible mediante dispositivos móviles.
